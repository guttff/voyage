1Voyage — couple’s vacation planner

Assumptions: two people paying $450 each every 2 weeks; contribution rules can start on a future date so the projection shows a change before it happens. Each vacation has a Final plan plus one option per person; anyone can add anywhere, and “Copy to…” moves items between options while keeping who added it and where it came from. The projection charges a trip in its start month using the Final cost (or the largest option while Final is empty) and flags trips that would put the balance below zero. Every option exports to a small JSON schema, and the importer accepts the same shape from ChatGPT (a ready prompt is in the Import dialog). All three views below are live and share one data model.

1aBoard — sidebar, projection, timeline + stats (from your sketch)
1bCompare — options side by side by day, one-click “→ Final”
1cPhone — same data, stacked; budget check pinned above the plan
